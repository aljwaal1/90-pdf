# Android text-to-speech regression checks

1. Read a short Arabic sentence; verify it completes.
2. Read a 5,000-character Arabic document; verify the whole document is spoken.
3. Start a second document during playback; verify the first stops.
4. Pause, resume, and stop playback.
5. Verify missing system voices produce a clear error.

Manual device verification is required; this checklist does not imply these cases passed.
