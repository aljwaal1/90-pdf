# 90 PDF — Android

Android port of [PDFCraft](https://github.com/PDFCraftTool/pdfcraft) targeting its full 90+ tool catalog.

The upstream application is licensed under **AGPL-3.0**. Source attribution and corresponding-source obligations must be maintained.

Workflows in `.github/workflows` bootstrap the full upstream source and prepare experimental Android builds. Android parity is not yet verified; do not treat CI artifacts as tested releases.
